Carregue o cronograma da obra

Use o Excel padrão do cronograma (mesmo modelo de Cronograma_SE_Campo_Formoso_CurvaS.xlsx). A plataforma lê três abas:

  • Cronograma: Disciplina, Grupo, Atividade, Início/Término Linha Base, Início, Término e Peso. Só as linhas com Disciplina preenchida entram no cálculo.
  • Feriados: dias com “Considerar? = S” saem do calendário (jornada de segunda a sábado).
  • Distribuição Real.: peso realizado por semana, que alimenta o % Real.

O % Prev. é o acumulado da linha de base até a data de corte, distribuído pelos dias úteis de cada atividade.

Como usar

  • Cada equipamento tem um ID ÁREA-FASE-TIPO-NN (ex.: LT-VM-TC-01). Cada atividade é o ID + etapa: .F fundação, .S suporte, .E equipamento, .C cabos.
  • Preencha o % de cada atividade na aba “Avanço” da planilha, salve e use Carregar planilha de avanço. O modelo passa para o modo Avanço da obra.
  • A última planilha carregada fica lembrada neste navegador.
  • Premissas: distâncias dos cortes A‑A/B‑B; alturas não cotadas lidas na escala 1:300; fase AZ igual à VM; casa de controle, GMGs e SA1 posicionados pela planta.
